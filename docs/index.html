Jubbsticks Additions for Peanuts

Turns dragonloverlord's unofficial Jubbsticks Additions port (UJAP-V0.0.2) into a mod zip for Peanuts Native. It all runs in your browser; nothing is uploaded.

  1. 1

    Get the port

    Download UJAP-BetaRelease-V002-Atmosphere.7z from the port's Releases (version UJAP-V0.0.2). Don't extract it. Please read his rules there first.

  2. 2

    Get the patch

    Download jub-port-patch.json from the latest release.

  3. 3

    Other ACNH mods you use (optional)

    Pick their .zip or .7z files, so the size table also covers the sizes they raised. Install this page's zip in Peanuts before your other mods: Peanuts uses the first-installed mod's copy of a file and has no reorder, so reinstall the others after it.

  4. 4

    Make the zip

Status

Pick both files.

Then, in Peanuts

Back up your save first: this mod adds items. Open ACNH's settings, then Install mod… > Zip file, and pick jubbsticks-additions-peanuts.zip. Peanuts rebuilds the game with the mod, which takes about 5 minutes. Then start a new game.

It's the port as is, minus what Peanuts can't load yet: the port's UnitIcon models and extra message files crash ACNH 3.0.3 on Peanuts (tested on an AYN Thor), so some new NPC lines may be missing. Its 40 new EventFlow dialogue flows are in, with its flow list merged into the 3.0.3 one. The page also puts back 79 vanilla item names the port's text file lacks, and gives it a size table made for 3.0.3.

Other mods that replace the same files (item tables, item names, the size table) will clash with it.

Please keep in mind

This is an unofficial beta of an unofficial port. Don't ask Jubbsticks or dragonloverlord for help with this zip: if something breaks on Peanuts, open an issue here.

The port is still being fixed, and the patch only fits UJAP-V0.0.2. When a new version of the port comes out, the page refuses it until there's a new patch here.

Offline play only, with your own copy of the game.
