Jubbsticks' Additions for Peanuts

Turns dragonloverlord's unofficial Jubbsticks Additions port (UJAP) into a mod zip for Peanuts Native. Add QoL Enhancements in the same go if you like. It all runs in your browser; nothing is uploaded.

What you get

The whole port: new items, new NPCs and their dialogue, stacks to 254 and unbreakable tools, with the new fruit and gem icons thanks to the memory fix, which always comes as its own zip. The page does not change the port's files; it only repackages them for Peanuts and makes the size table cover the other mods you pick.

Other mods that replace the same files (item tables, item names, the size table) will clash with it.

Please keep in mind

This is a fan port of a fan port. Don't ask Jubbsticks or dragonloverlord for help with this zip: if something breaks on Peanuts, open an issue here.

The page works with any release of the port (Atmosphere download). Problems in the port itself are the port's to fix.

Offline play only, with your own copy of the game.
