Status

Pick both files.

Then, in Peanuts

Open ACNH's settings, then Install mod… > Zip file, and pick jubbsticks-additions-peanuts.zip. Put it last in the mod order (after ACNH-Combined and QoL). Peanuts rebuilds the game with the mod, which takes about 5 minutes. Start a new game, and back up your save first: this mod adds items.

It is made to sit next to ACNH-Combined. It carries a merged size table and item tables that keep Combined's edits (doubled Daily rewards, banana names). Stack sizes are the port's: most stackable items go up to 254. Combined's eight flower and fruit models stay Combined's. The port's EventFlow files, UnitIcon models and extra message files are left out: they hang or crash ACNH 3.0.3 on Peanuts (tested on an AYN Thor). Some new NPC dialogue is missing because of that.

Please keep in mind

This is an unofficial beta of an unofficial port. Don't ask Jubbsticks or dragonloverlord for help with this zip: if something breaks on Peanuts, open an issue here.

The port is still being fixed, and the patch only fits UJAP-V0.0.2. When a new version of the port comes out, the page refuses it until there's a new patch here.

Offline play only, with your own copy of the game.
