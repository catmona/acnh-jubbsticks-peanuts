Optional fixes

Fixes you can leave out. The ones that are ticked go in when you make the zip.

What you get

The whole port: new items, new NPCs and their dialogue, stacks to 254 and unbreakable tools, with the new fruit and gem icons thanks to the memory fix. The page also fills in the bits of 3.0.3 text the port is missing and gives it a size table made for 3.0.3.

Other mods that replace the same files (item tables, item names, the size table) will clash with it.

Please keep in mind

This is a fan port of a fan port. Don't ask Jubbsticks or dragonloverlord for help with this zip: if something breaks on Peanuts, open an issue here.

The page works with port version UJAP-V0.0.2. When a new version of the port comes out, I'll add a patch for it here.

Offline play only, with your own copy of the game.
